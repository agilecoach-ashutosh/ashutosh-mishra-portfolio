# Ashutosh Mishra - Portfolio

Personal portfolio for **Ashutosh Mishra**, Enterprise Transformation & Delivery Leader.

## Positioning

The site is designed for recruiters and senior leaders. It presents transformation outcomes, flow and delivery expertise, coaching credentials, engineering roots, and selected AI-assisted builds including Agile Orbit and Presence Coach.

## Experience

- Static HTML, CSS and vanilla JavaScript
- Custom perspective-based 3D particle/flow canvas, no framework or build step
- Responsive layout with dark/light themes
- Reduced-motion accessibility support
- GitHub Pages ready

## Run locally

Open `index.html` directly or serve the folder with any static file server.

## Deploy

Enable GitHub Pages from the repository's `main` branch and `/ (root)` folder.
